Урок 7-4: Повелительное наклонение

Лекция: Повелительное наклонение в якутском языке

Повелительное наклонение выражает приказ, просьбу, совет, побуждение к действию. В якутском языке оно имеет различные формы для разных лиц и чисел, а также вежливую форму. В отличие от русского языка, где повелительная форма есть только для 2-го лица, в якутском языке она существует для 1-го, 2-го и 3-го лица.

Важно: Повелительная форма в якутском языке имеет специальные суффиксы для каждого лица и числа. Форма 2-го лица единственного числа совпадает с основой глагола.

Формы повелительного наклонения

2-е лицо единственное число (эн)

Совпадает с основой глагола (без суффикса). Для глаголов, оканчивающихся на гласный, добавляется -й.

Глагол (основа)Повелительная формаПеревод
бар (идти)бариди
кэл (прийти)кэлприди
көр (смотреть)көрсмотри
аах (читать)аахчитай
олор (сидеть)олорсиди
турар (вставать)турвстань

2-е лицо множественное число (эһиги)

Образуется с помощью суффиксов -ҥ, -ҥыт, -ҥит.

ГлаголПовелительная формаПеревод
барбар-ыҥ, барыҥидите
кэлкэл-иҥ, кэлиҥпридите
көркөр-үҥ, көрүҥсмотрите
аахаах-хыҥ, ааххыҥчитайте

1-е лицо единственное число (мин) - желательная форма

Выражает желание говорящего. Образуется с помощью суффикса -(ы)ым.

ГлаголФормаПеревод
барбарыым(я) пойду-ка, хочу пойти
кэлкэлиэм(я) приду-ка
көркөрүөм(я) посмотрю-ка

1-е лицо множественное число (биһиги)

Выражает побуждение к совместному действию («давай сделаем»). Образуется с помощью суффиксов -иэх, -уох, -үөх + -э.

ГлаголФормаПеревод
барбиһиги бараах-бытдавайте пойдём
кэлкэлиэхдавайте придём
үөрэнүөрэниэхдавайте научимся

Более употребительная форма: глагол в будущем времени + этиҥ. Например: барабыт этиҥ (давайте пойдём).

3-е лицо единственное и множественное число

Выражает приказ или позволение для 3-го лица («пусть сделает»). Образуется с помощью суффиксов -тун, -түн, -тын, -тин.

ГлаголФорма (ед.ч.)Форма (мн.ч.)Перевод
барбардынбардыннарпусть пойдёт / пойдут
кэлкэллэнкэллэннэрпусть придёт / придут
көркөрдүнкөрдүннэрпусть посмотрит / посмотрят
аахаахтынаахтыннарпусть прочитает / прочитают

Вежливая форма повелительного наклонения

Для вежливой просьбы используются частицы -аа, -ээ, -оо, -өө или слово буолуо (пожалуйста).

  • Кэлээ — приходи-ка (вежливо)
  • Көрөө — посмотри-ка
  • Олороо — садись-ка
  • Тураа — встань-ка

Отрицательная форма повелительного наклонения

Образуется с помощью отрицательного аффикса -ма (после согласных) или -ыма (после гласных).

ГлаголУтвердительнаяОтрицательнаяПеревод
барбарбакыма, барбане ходи
кэлкэлкэлимэне приходи
көркөркөрүмэне смотри
аахаахааххымане читай

Примеры предложений

  • Кэл! — Приди!
  • Кэлиҥ! — Придите!
  • Маны аах. — Прочитай это.
  • Суруйбаккын? — Ты напишешь? (вежливый вопрос-просьба)
  • Олороо, миэстэҕэ. — Садись, пожалуйста, на место.
  • Көрүмэ ол киинэни. — Не смотри этот фильм.
  • Барыах, кинотеатрга. — Давайте пойдём в кинотеатр.
  • Кэллэн кини. — Пусть он придёт.
  • Үөрэниэх саха тылын. — Давайте учить якутский язык.
  • Барба эн онно. — Не ходи ты туда.
  • Эппиэттээ! — Отвечай!
  • Миэхэ этээ. — Скажи мне (пожалуйста).

Важные замечания

В разговорной речи часто используются краткие формы повелительного наклонения. Вежливая форма с частицей -аа является очень употребительной в повседневном общении. Формы 1-го лица множественного числа часто заменяются конструкцией с глаголом в будущем времени.
